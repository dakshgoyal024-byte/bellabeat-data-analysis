
# Bellabeat Data Analysis

## Project Overview

A data analytics case study based on the Google Data Analytics Capstone Project.

This project analyzes Fitbit fitness tracker data to identify consumer usage patterns and develop marketing recommendations for Bellabeat.

## 1. Ask

### Business Task

Analyze smart device fitness data to understand how consumers use their devices, identify patterns in activity and health-related behavior, and provide data-driven recommendations to support Bellabeat's marketing strategy.

### Guiding Questions

1. How active are users on a daily basis?
2. How much time do users spend being sedentary?
3. What patterns exist between daily activity and calories burned?
4. How consistently do users track their activity?
5. How can these insights inform Bellabeat's marketing strategy?
